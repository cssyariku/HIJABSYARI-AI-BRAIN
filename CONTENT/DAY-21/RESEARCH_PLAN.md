# DAY 21 — Audience Research Plan

## Purpose

Turn Stories interactions into structured audience evidence for future content. This document contains a collection plan, not findings.

## Coding fields

| Field | Example values |
|---|---|
| Category | framing; stay/shift; material/care; color/outfit; other |
| Specific problem | front curve collapses; fabric slides; color feels hard to match |
| Context | campus; office; commute; event; long activity |
| Hijab form/material | pashmina; square; voal; chiffon; jersey; unknown |
| Attempt already made | inner; magnet/pin; wash method; color test; none stated |
| Frequency | one mention; repeated across multiple responses |
| Evidence source | Poll; Questions; reply |

## Interpretation rules

- Poll results show only the offered categories; they do not prove the absent categories are unimportant.
- Questions responses carry richer detail but require more effort, so compare them separately from Poll taps.
- Preserve audience wording when recording a problem; do not invent or “clean up” it into a stronger claim.
- Do not call a topic a winner from one response or one Stories sequence.
- A future content priority should require either repeated specific language, supporting Insights, or explicit user direction.
- No response or metric is recorded until supplied by Instagram after publication.
