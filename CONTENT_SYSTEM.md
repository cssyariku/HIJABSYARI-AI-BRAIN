# CONTENT SYSTEM — Hijab Syari Indonesia

**Version:** 1.0

## 1. CONTENT OPERATING SYSTEM

The system converts audience problems and discoveries into repeatable media assets:

**Research → Opportunity → Score → Produce → Publish → Measure → Learn → Scale/Iterate/Kill**

One topic should be treated as an asset cluster, not a single post:

**1 Research → 1 Core Idea → Carousel → Reel → Stories → Text derivative → Audience feedback → Next idea**

---

## 2. OPPORTUNITY SOURCES

Use:
- Instagram search/autocomplete where available;
- public competitor observations;
- Google/search trends where relevant;
- comments/questions;
- Story polls;
- audience DMs supplied by user;
- modest-fashion discussions;
- seasonal moments;
- recurring hijab problems;
- analytics from prior posts.

For current trends, research before claiming something is “viral/trending”.

Never fabricate:
- competitor engagement rate;
- reach;
- saves;
- private Insights;
- audience demographics not publicly verified.

---

## 3. CONTENT SCORING

Before production, score 1–5:

| Dimension | Question |
|---|---|
| Hook | Can it earn attention in 2–3 seconds? |
| Relevance | Is it a real audience need/desire? |
| Utility | Does it teach/solve something? |
| Saveability | Would someone need it later? |
| Shareability | Would someone send it to a friend? |
| Visual Potential | Can it be shown clearly? |
| Originality | Is the angle distinct enough? |
| Feasibility | Can we produce it well with available tools? |

Target production threshold: **28/40** as a planning heuristic, not an algorithmic truth.

If below threshold, improve angle before production.

## 4. HOOK ENGINE

Generate 3–5 variants for important posts.

### Problem
“Hijab selalu maju? Bisa jadi bukan karena bahannya.”

### Contrarian
“Tidak semua warna nude membuat wajah terlihat lebih cerah.”

### Curiosity
“Kenapa hijab yang bagus di mannequin terasa berbeda ketika dipakai?”

### Specific
“5 warna hijab yang gampang dipadukan dengan outfit hitam.”

### Mistake
“3 kesalahan kecil yang bikin styling hijab terlihat kurang rapi.”

### Comparison
“Voal atau chiffon: kapan sebaiknya pakai masing-masing?”

### Identity/context
“Kalau lemari kamu dominan earth tone, simpan kombinasi ini.”

Avoid:
- fake urgency;
- misleading “rahasia”;
- “nomor 3 bikin syok”;
- unsupported absolutes.

## 5. CAROUSEL SYSTEM

Primary objective: saves/shares/depth.

Default 5–8 slides, adjust to content.

Structure:
1. Hook
2. Why/context
3–6. Core value
7. Summary/comparison
8. Relevant CTA

Rules:
- one main idea per slide;
- mobile-readable;
- avoid paragraph walls;
- cover must communicate benefit quickly;
- caption adds context rather than duplicating slides.

Example Color Lab:
1. “Pakai Baju Hitam? Jangan Selalu Ambil Hijab Hitam.”
2. Black is flexible; mood changes by hijab color.
3. Cream — clean/soft
4. Mocha — warm
5. Taupe — muted
6. Burgundy — richer contrast
7. Grey — cool/minimal
8. Comparison + “Save untuk referensi.”

---

## 6. REELS SYSTEM

Primary objective: discovery/retention.

Default structure:
- 0–2 sec: hook
- 2–8 sec: value/visual change
- 8–15 sec: payoff/comparison
- end: loop or useful CTA

Do not force every Reel to 15 seconds. Test duration.

Visual:
- strong first frame;
- movement subtle and believable;
- on-screen text concise;
- visual changes should correspond to information.

Example:
“4 Warna Hijab untuk Outfit Hitam”
- hook: PAKAI BAJU HITAM?
- Cream
- Mocha
- Burgundy
- Grey
- end: “Kamu pilih yang mana?”

## 9. WEEKLY OPERATING RHYTHM

### Research
Generate ~20 raw opportunities.

### Editorial selection
Score and choose 7–10 best opportunities.

### Batch production
- scripts;
- visual prompts;
- image generation;
- layouts;
- image-to-video;
- captions;
- QA.

### Publish
Keep experiment variables controlled where possible.

### Weekly review

- WHY;
- evidence;
- next hypothesis;
- action: SCALE / ITERATE / RETEST / STOP.

## 12. WINNER LOGIC

Do not define winner only by views.

A post can be:
- **Discovery Winner** — strong non-follower reach/retention.
- **Utility Winner** — strong save/share.
- **Growth Winner** — strong follow conversion.
- **Community Winner** — meaningful comments/responses.

After ~20–30 relevant posts:
- establish median by format/objective;
- inspect top quartile;
- identify repeated mechanisms;
- clone mechanism, not exact post.

| Variant |
| Period |
| Comparable content |
| Metrics |
| Result |
| Confidence/limitations |

Rules:
- change one major variable where practical;
- do not declare causality from tiny samples;
- account for topic strength;
- retest promising patterns.

After fit improves, use approximate portfolio:
- 70% proven;
- 20% variations;
- 10% experiments.

Early phase can explore more broadly.

## 15. COMMUNITY SYSTEM

Every week mine:
- repeated questions;
- objections;
- terminology audience uses;
- color/material requests;
- occasion requests;
- product questions.

Turn repeated audience language into hooks.

---

## 16. REPURPOSING RULE

Do not merely resize.

Example:
Research: “Hijab for black outfit”

Carousel:
deep comparison and saveable reference.

Reel:
fast visual transformation.

Stories:
A/B vote.

Text:
“Black outfit is not the problem; the hijab color changes the mood.”

Each format should use its native strength.

## 17. QA CHECKLIST

Before publish:

### Editorial
- Is claim accurate?
- Is benefit clear?
- Is it relevant?
- Any unnecessary absolute claim?

### Copy
- Strong hook?
- Natural Indonesian?
- No generic AI tone?
- CTA relevant?

### Visual
- readable on phone?
- consistent?
- AI anatomy/fabric correct?
- no fake text/logo?
- modest and appropriate?

### Strategic
- pillar clear?
- objective clear?
- KPI selected?
- experiment tagged if applicable?

### Commercial
- any sponsorship/affiliate disclosure needed?
- recommendation remains useful without purchase?
